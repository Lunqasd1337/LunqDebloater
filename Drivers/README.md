# Папка для драйверов

Положите сюда драйверы, которые нужно встроить в образ: распакованные файлы `.inf` вместе с остальными файлами драйвера (`.sys`, `.cat` и т.д.). Подпапки можно использовать любые, скрипт найдёт все `.inf` сам.

Откуда взять драйверы:

- **С компьютера, на который будет ставиться система** (если на нём уже работает Windows):
  ```powershell
  Export-WindowsDriver -Online -Destination .\Drivers
  ```
  Команда выгрузит все сторонние драйверы, которые сейчас установлены.
- **С сайта производителя** ноутбука, материнской платы или устройства. Если драйвер скачивается как `.exe`, его нужно распаковать: многие установщики распаковываются 7-Zip или имеют ключ вроде `/extract`. Драйвер в виде `.exe` без `.inf` встроить нельзя.
- **Из каталога Центра обновления Майкрософт**: там драйверы лежат в `.cab`, их можно распаковать (`expand -F:* файл.cab папка`).

Драйверы контроллеров дисков (Intel RST/VMD, RAID) имеет смысл добавить и в установщик, иначе он может не увидеть диск. В пошаговом режиме скрипт спросит об этом сам, а при запуске с параметрами нужен ключ `-DriversToSetup`.
