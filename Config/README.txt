Папка настроек LunqDebloater
============================

Всё, что лежит в этой папке, попадает в образ. Перед сборкой скрипт покажет сводку
«Что войдёт в образ», и лишнее можно выключить по номеру, ничего не удаляя отсюда.

  Profile.json   Что удалить из Windows и какие настройки реестра внести. Профиль разбит
                 на категории, их можно включать и выключать перед сборкой. Можно положить
                 сюда ещё профили (*.json), тогда скрипт спросит, какой взять.

  Apps.txt       Программы, которые поставятся через winget при первом входе в Windows.
                 Одна программа в строке, Id из winget (найти: winget search <название>).
                 Строки с # в начале пропускаются.

  Scripts\       Ваши скрипты *.ps1. Выполнятся один раз при первом входе, после установки
                 программ, по порядку имён (10-settings.ps1, 20-cleanup.ps1), с правами
                 администратора. Остальные файлы из этой папки тоже копируются, и скрипты
                 могут обращаться к ним по относительному пути.

  Drivers\       Драйверы: распакованные .inf вместе с .sys, .cat и остальными файлами,
                 подпапки любые. Windows сама поставит их во время установки.
                 Выгрузить все драйверы с работающего компьютера:
                     Export-WindowsDriver -Online -Destination .\Config\Drivers
                 Драйвер в виде .exe нужно сначала распаковать (7-Zip или ключ /extract).
                 Драйверы из .cab каталога Майкрософт: expand -F:* файл.cab папка

  Updates\       Обновления .msu или .cab с https://www.catalog.update.microsoft.com
                 (ищите, например, «Windows 11 Version 26H2 x64», берите последнее
                 накопительное обновление). Если для обновления в каталоге несколько
                 файлов, скачайте все: они ставятся по возрастанию номера KB.

Драйверы и обновления не попадают в git, остальное попадает.

Как работают программы и скрипты после установки
------------------------------------------------
Программы и скрипты копируются в образ, в C:\Windows\Setup\Scripts\Lunq\User, и
запускаются через FirstLogonCommands в Windows\System32\Sysprep\unattend.xml.
При первом входе откроется окно с ходом работы. Скрипт дождётся интернета (до 5 минут)
и winget (до 10 минут), тихо поставит программы, выполнит скрипты и закроет окно.
Если интернета нет, программа не поставилась или окно закрыли на середине, недоделанное
повторится при следующем входе (задание планировщика LunqFirstLogon, до 5 попыток).
Скрипт с ошибкой повторно не запускается. Когда всё сделано, копии скриптов и файлов рядом
с ними удаляются с диска (там могут быть пароли), остаются Apps.txt и лог:
C:\Windows\Setup\Scripts\Lunq\FirstLogon.log

Скрипты в UTF-8 без BOM при сборке пересохраняются с BOM: иначе Windows PowerShell 5.1
прочитает их как ANSI, и русский текст в кавычках сломает скрипт.

Если вы используете свой autounattend.xml с разделом oobeSystem, Windows возьмёт его,
и программы со скриптами не запустятся. Тогда добавьте команду из unattend.xml в свой файл.
То же самое случится, если при записи флешки через Rufus отметить в его окне хоть одну
настройку Windows, в том числе обход требований TPM, Secure Boot и памяти. Обход и
локальную учётную запись лучше включить в файле ответов LunqDebloater (пункты в сводке
«Что войдёт в образ»). Если без настроек Rufus не обойтись, после установки запустите
всё вручную от имени администратора:
    powershell -NoProfile -ExecutionPolicy Bypass -File C:\Windows\Setup\Scripts\Lunq\FirstLogon.ps1

Несколько наборов настроек
--------------------------
Папку можно скопировать, например в Config-Office, и собирать с ней:
    .\LunqDebloater.ps1 -ConfigPath .\Config-Office
