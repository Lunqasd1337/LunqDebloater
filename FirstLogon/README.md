# Папка первого входа

Всё, что лежит здесь, выполнится **один раз при первом входе** в установленную Windows. Откроется окно с ходом работы, и после завершения оно закроется само.

- **`Apps.txt`**: программы, которые нужно поставить через winget, по одному Id в строке. Образец лежит в `Apps.example.txt`: скопируйте его как `Apps.txt` и оставьте нужное. Найти Id программы можно командой `winget search <название>`.
- **`*.ps1`**: ваши скрипты. Они выполнятся после установки программ, по порядку имён (`10-settings.ps1`, `20-cleanup.ps1`), с правами администратора. Текущей папкой будет эта папка, поэтому файлы рядом со скриптом доступны по относительному пути.
- Остальные файлы (установщики, конфиги) тоже копируются в образ, и скрипты могут ими пользоваться.

Как это работает:

- Папка копируется в образ, в `C:\Windows\Setup\Scripts\Lunq\User`.
- Скрипт запускается через `FirstLogonCommands` в `Windows\System32\Sysprep\unattend.xml`. `SetupComplete.cmd` для этого не годится: Windows не запускает его, если в BIOS зашит OEM-ключ (почти все ноутбуки с Home и Pro).
- Перед установкой программ скрипт ждёт интернета (до 5 минут) и winget (до 10 минут, после установки он регистрируется не сразу).
- Если интернета нет, ваши скрипты всё равно выполнятся, а программы поставятся при следующем входе. Для этого создаётся задание планировщика `LunqFirstLogon`, всего до 5 попыток.
- Лог пишется в `C:\Windows\Setup\Scripts\Lunq\FirstLogon.log`.

Если вы используете свой `autounattend.xml` с разделом `oobeSystem`, Windows возьмёт его, а не файл LunqDebloater, и первый вход не сработает. В этом случае добавьте команду из `unattend.xml` в свой файл.
