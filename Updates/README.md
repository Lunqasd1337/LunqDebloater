# Папка для обновлений

Положите сюда файлы `.msu` или `.cab`, которые нужно встроить в образ. В пошаговом режиме скрипт сам предложит их установить, а при запуске с параметрами укажите `-UpdatesPath .\Updates`.

Где взять: [каталог Центра обновления Майкрософт](https://www.catalog.update.microsoft.com). Ищите по версии и архитектуре, например `Windows 11 Version 26H2 x64`, и берите последнее накопительное обновление (Cumulative Update). Можно добавить обновление .NET Framework.

Если для накопительного обновления на странице каталога указано несколько файлов (контрольное и последнее обновление), скачайте все: скрипт ставит их по возрастанию номера KB.

Файлы `.msu` и `.cab` в этой папке не попадают в git.
