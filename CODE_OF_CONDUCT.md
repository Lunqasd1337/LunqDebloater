# Правила общения

English: [see below](#code-of-conduct)

В issue, PR и обсуждениях проекта действуют простые правила:

- Общайтесь вежливо и по делу, критикуйте код и решения, а не людей.
- Не допускайте оскорблений, травли, угроз и дискриминации ни по какому признаку.
- Не публикуйте чужие личные данные без согласия.
- Помните, что у людей разный опыт: на вопрос новичка отвечайте так же, как на вопрос опытного участника.

Если кто-то нарушает эти правила, сообщите владельцу репозитория через [issue](https://github.com/Lunqasd1337/LunqDebloater/issues) или закрытое сообщение о проблеме (вкладка **Security**, если дело серьёзное). Владелец может скрыть или удалить сообщение, закрыть обсуждение или заблокировать участника.

Правила основаны на [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Code of conduct

Simple rules apply in the project's issues, PRs and discussions:

- Be polite and stay on topic; criticize code and decisions, not people.
- No insults, harassment, threats or discrimination of any kind.
- Do not publish other people's personal data without their consent.
- People have different experience: answer a beginner's question the same way you would answer an experienced contributor.

If someone breaks these rules, tell the repository owner through an [issue](https://github.com/Lunqasd1337/LunqDebloater/issues) or a private report (the **Security** tab, if it is serious). The owner may hide or delete a message, lock a discussion or block a participant.

These rules are based on the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
